How to use this workbook

Start with the level that feels comfortable. Try the challenge before opening the hint. Write your code in your Python editor (such as IDLE or your school IDE), not just in the box below. The boxes are optional notes or places to paste your code; this web page does not run Python. Save your Python files separately.

Tick a task once you have tested it. Your ticks and notes are saved in this browser only. If you open the file on another computer, they will not transfer.

Testing habit: For each solution, test a normal input, a boundary input, and a surprising input where appropriate. If you find an error, write down what you changed.

Remember: indentation matters; = assigns, == compares; return sends a value back to the caller; and input() produces a string until you convert it.
